智能背景移除附加组件利用 AI 能力，能够自动识别并保留图像主体，同时移除背景，生成背景透明的图片。该组件提供了多种图像处理模型，支持精细化图像主体边缘处理模式，能显著提升图像处理效率、降低人工成本。本文介绍如何使用智能背景移除附加组件。
![Image](https://lf6-volc-editor.volccdn.com/obj/volcfe/sop-public/upload_811c93701628afe2e2f34e01dc73d4a1.image =500x)
<span id="应用场景"></span>
# 使用场景
以下为智能背景移除组件的主要使用场景。

* **弹幕穿人**：在优酷、爱奇艺、哔哩哔哩等视频应用中，实现弹幕穿透人物的效果，避免弹幕遮挡视频主体，从而提升用户的观看体验。
* **背景替换**：在在线会议、直播、在线图片编辑或证件照制作等场景中，自动移除人物或物体的背景，并替换为自定义背景。
* **素材生成**：从图片中精准分离出主体，方便您将其用于制作新的广告或宣传素材。

:::tip
如果图像不包含明显主体，veImageX 将返回原图。
:::
<span id="b8e395fc"></span>
# 使用限制
为确保能够生成图像，请满足以下限制。

* **输入大小**：单张图 <= 10 MB。如果超出 10 MB，请先通过模板压缩图片大小。
* **输入分辨率**：短边 ≤ 4320 px，长边 ≤ 7680 px。如果为其他分辨率，请先通过模板变更图片分辨率。
* **输入格式**：.png、.jpg、.jpeg、.webp、.tiff、.bmp、.ico。如果为其他格式，请先通过模板变更图片格式。
* **输出分辨率**：短边 ≤ 4320 px，长边 ≤ 7680 px。可通过模板二次处理为其他分辨率。
* **输出格式**：.png、.jpeg、.webp。可通过模板二次处理为其他格式。
* **输出大小**：单张图 <= 10 MB。

### 方式一：通过 API 调用
<span id="12c51325"></span>
#### 同步处理
调用同步处理接口 [AIProcess](https://www.volcengine.com/docs/508/1515915)，提交一条 URL 或 URI 资源执行同步 AI 图像处理任务。
**请求示例**
```JSON
POST https://imagex.volcengineapi.com/?Action=AIProcess&Version=2023-05-01
{
    "ServiceId": "91**2g", // 必选。服务 ID。
    "WorkflowTemplateId": "system_workflow_image_segment", // 必选。模板 ID。
    "WorkflowParameter": "{\"Input\":{\"ObjectKey\":\"a.png\",\"DataType\":\"uri\"},\"SegmentParam\":{\"ModelId\":\"humanv2\",\"Refine\": true,\"Contour\":{\"Color\":\"#FFFFFF\",\"Size\":10},\"TransBg\":false,\"OutFormat\":\"png\"}}" // 必选。模板参数。
}
```

其中，

* `ServiceId`：服务 ID，可从[服务管理](https://console.volcengine.com/imagex/service_manage/)页面获取。
* `WorkflowTemplateId`：取值固定为 `system_workflow_image_segment`。
* `WorkflowParameter`：根据[输入参数](/docs/508/124671#1aadcc14)，设置该参数取值。

**返回示例**
```JSON
{
    "ResponseMetadata": {
        "RequestId": "20230604110420****100232280022D31",
        "Action": "AIProcess",
        "Version": "2023-05-01",
        "Service": "ImageX",
        "Region": "cn-north-1"
    },
    "Result": {
        "Output": "{\"ObjectKey\":\"a.png\",\"Size\":54509,\"Format\":\"png\"}"
    }
}
```

`Output` 的参数含义详见[输出参数](/docs/508/124671#39d72cab)。

## 输出参数
veImageX 服务会将输出参数序列化为 JSON 字符串后作为 [AIProcess](https://www.volcengine.com/docs/508/1515915) 接口、[回调](https://www.volcengine.com/docs/508/1526662)或 [GetImageAIDetails](https://www.volcengine.com/docs/508/1515913) 接口的 `Output` 参数返回。
:::tip
生成的图像在控制台**资源管理**页面默认不展示，仅支持通过不包含 `tos-*-i-*` 前缀的存储 URI 搜索。
:::

| | | | | \
|参数 |类型 |示例值 |说明 |
|---|---|---|---|
| | | | | \
|ObjectKey |String |a.png |生成图像在指定服务 ID 下不包含 `tos-*-i-*` 前缀的存储 URI。 |
| | | | | \
|Size |Integer |38656 |生成图像的大小，单位为字节。 |
| | | | | \
|Format |String |png |生成图像的格式。 |
