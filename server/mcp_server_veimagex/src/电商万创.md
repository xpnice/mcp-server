# 使用场景
以下为电商万创组件的主要使用场景。

* **电商平台：** 帮助平台商家提升商品视觉效果，提高商品转化率。

# 使用限制
为确保能够生成图像，请满足以下限制。

* **输入分辨率**：短边 ⩾ 512 px，长边 ⩽ 1024 px。如果为其他分辨率，请先通过模板变更图片分辨率。
* **输入大小**：单张图 <= 10 MB。如果超出 10 MB，请先通过模板压缩图片大小。
* **输入格式**：.png、.jpg、.jpeg、.webp。如果为其他格式，请先通过模板变更图片格式。
* **输出格式**：.png。可通过模板二次处理为其他格式。
* **输出分辨率**：短边 ⩾ 512 px，长边 ⩽ 1024 px。可通过模板二次处理为其他分辨率。
