# 使用限制
为确保能够生成图像，请满足以下限制。

* **输入大小**：单张图 <= 10 MB。如果超出 10 MB，请先通过模板压缩图片大小。
* **输入分辨率**：15 px ≤ 短边 ≤ 1440 px，15 px ≤ 长边 ≤ 2560 px。如果为其他分辨率，请先通过模板变更图片分辨率。
* **输入格式**：.png、.jpg、.jpeg、.webp、.tiff、.bmp、.heic。如果为其他格式，请先通过模板变更图片格式。
* **输出大小**：单张图 <= 10 MB。
* **输出格式**：.png。可通过模板二次处理为其他格式。

### 方式一：通过 API 调用
<span id="c9ebb949"></span>
#### 同步处理
调用同步处理接口 [AIProcess](https://www.volcengine.com/docs/508/1515915)，提交一条 URL 或 URI 资源执行同步 AI 图像处理任务。
**请求示例**
```JSON
POST https://imagex.volcengineapi.com/?Action=AIProcess&Version=2023-05-01
{
    "ServiceId": "91**2g", // 必选。服务 ID。
    "WorkflowTemplateId": "system_workflow_ai_workflow_psoriasis", // 必选。模板 ID。
    "WorkflowParameter": "{\"Input\":{\"ObjectKey\":\"a.png\",\"DataType\":\"uri\"},\"AiWorkflowParam\":{\"ModelId\":\"default\"}}" // 必选。模板参数。
}
```

其中，

* `ServiceId`：服务 ID，可从[服务管理](https://console.volcengine.com/imagex/service_manage/)页面获取。
* `WorkflowTemplateId`：取值固定为 `system_workflow_ai_workflow_psoriasis`。
* `WorkflowParameter`：根据[输入参数](/docs/508/2129183#d30790ed)，设置该参数取值。

**返回示例**
```JSON
{
    "ResponseMetadata": {
        "RequestId": "20230604110420****100232280022D31",
        "Action": "AIProcess",
        "Version": "2023-05-01",
        "Service": "ImageX",
        "Region": "cn-north-1"
    },
    "Result": {
        "Output": "{\"ModelId\":\"default\",\"ExecuteId\":\"75869368****0236223\",\"Output\":{\"Format\":\"png\",\"ObjectKey\":\"a.png\",\"Size\":704659},\"Code\":0,\"ErrorMessage\":\"\"}"
    }
}
```

`Output` 的参数含义详见[输出参数](/docs/508/2129183#f3f3aa56)。
<span id="b4127d7f"></span>

:::

           "Method": "HTTP", // 必选。回调方式，取值固定为 HTTP。
           "Endpoint": "https://demo.com", // 必选。回调地址，用于接收处理结果。
           "DataFormat": "JSON", // 可选。回调数据格式，支持取值 XML 和 JSON。
           "Args": "product id", // 可选。业务自定义回调参数。

       "WorkflowParameter": "{\"AiWorkflowParam\":{\"ModelId\":\"default\"}}", // 必选。模板参数。

   * `WorkflowTemplateId`：取值固定为 `system_workflow_ai_workflow_psoriasis`。
