大模型画质评估附加组件利用 AI 能力，通过一次 Prompt 查询，可以预测出图像在以下 5 个维度的画质分数：Blur（模糊评分）、Noise（噪点评分）、Artifacts（伪影评分）、Aesthetics（美学评分）和 Overall（综合评分）。本文介绍如何使用大模型画质评估附加组件。
<span id="5975cb81"></span>
# 使用场景
大模型画质评估组件输出的评分适用于任何需要自动判断图像质量、筛选低质图、优化用户体验的场景，尤其是 AI 生成内容平台、电商、图库、相册 App、训练数据清洗等。典型场景如下所示。
<span id="bf869500"></span>
## AI 生成图像质量筛选
自动过滤低质量 AI 图像、AIGC 生图。例如平台仅允许上传综合评分大于 70 的图像。
<span id="8428f503"></span>
## 内容审核
自动识别模糊、噪声大、有压缩痕迹的图片，避免低质内容上线。例如电商平台上如果用户上传的商品图模糊评分小于 60，则自动打回重传。
<span id="1a15a380"></span>
## 图像增强工具反馈
在 Photoshop 插件、在线修图工具等图像增强工具中，如果用户上传的图片模糊评分较低，则建议"去模糊"或"降噪"。
<span id="2e788d0c"></span>
## AI 模型训练数据清洗
在训练视觉模型前，自动剔除低质量图像，避免影响模型性能。例如在训练人脸识别模型前，过滤掉模糊评分小于 65 的图像。
<span id="ef0ed0b2"></span>
## 图库推荐
自动评估上传图像的质量，决定是否推荐到首页。例如美学评分小于 70 的图片，不会进入"编辑推荐"流。
<span id="55144402"></span>
## 手机相册智能分类
自动标记“模糊照片”或“噪点多”的照片，建议用户删除或修复。例如 iPhone 相册的“清理建议”功能。
<span id="8fa0bba5"></span>
# 使用限制
为确保能够获取评分，请满足以下限制。

* **输入分辨率**：短边 ≤ 4320 px，长边 ≤ 7680 px。如果为其他分辨率，请先通过模板变更图片分辨率。
* **输入格式**：.png、.jpeg、.webp、.heic。如果为其他格式，请先通过模板变更图片格式。

<span id="1d85dc2f"></span>
# 性能指标
处理耗时：处理一张 1080P 分辨率的图像，模型耗时 2 秒左右。

#### 同步处理
调用同步处理接口 [AIProcess](https://www.volcengine.com/docs/508/1515915)，提交一条 URL 或 URI 资源执行同步 AI 图像处理任务。
**请求示例**
```JSON
POST https://imagex.volcengineapi.com/?Action=AIProcess&Version=2023-05-01
{
    "ServiceId": "91**2g", // 必选。服务 ID。
    "WorkflowTemplateId": "system_workflow_image_quality_evaluate", // 必选。模板 ID。
    "WorkflowParameter": "{\"Input\":{\"ObjectKey\":\"example.webp\",\"DataType\":\"uri\"},\"QualityEvaluateParam\":{\"ModelId\":\"default\",\"PromptId\":\"default\",\"MediaType\":\"image\"}}" // 必选。模板参数。
}
```

其中，

* `ServiceId`：服务 ID，可从[服务管理](https://console.volcengine.com/imagex/service_manage/)页面获取。
* `WorkflowTemplateId`：取值固定为 `system_workflow_image_quality_evaluate`。
* `WorkflowParameter`：根据[输入参数](/docs/508/1913830#fd24bb67)，设置该参数取值。

**返回示例**
```JSON
{
    "ResponseMetadata": {
        "RequestId": "20230604110420****100232280022D31",
        "Action": "AIProcess",
        "Version": "2023-05-01",
        "Service": "ImageX",
        "Region": "cn-north-1"
    },
    "Result": {
        "Output": "{\"aesthetics\":41,\"artifacts\":58.14,\"blur\":51,\"noise\":93.86,\"overall\":38.14}"
    }
}
```

`Output` 的参数含义详见[输出参数](/docs/508/1913830#48aa4583)。
